它是什么

OpenClaw Portable 是一个「开箱即用」的 AI 助手便携包。它把 OpenClaw 核心程序、Node.js 运行时、AI 模型配置面板和技能市场全部打包在一个文件夹里。你什么都不用装，解压、双击，就能在 Windows / macOS / Linux 上直接运行。

✨
为什么叫"便携版"？整个文件夹复制到 U 盘，插到任何机器上都能直接用。所有配置和对话记录保存在 U 盘里，宿主机不留痕迹。

能做什么

功能说明
AI 对话15+ 模型：DeepSeek、Kimi、Claude、GPT-4o 等
聊天平台接入微信 / 飞书 / QQ / Telegram / Discord / Slack 等 12 个渠道
本地模型llama.cpp / LM Studio / Ollama 离线可用
技能市场13,000+ AI Skills 浏览和安装
配置持久化配置保存在 data/ 目录，跨系统共享

常见问题

可以在不同电脑上使用同一个 U 盘吗？
可以。所有配置和对话记录都保存在 U 盘的 data/ 目录，在不同电脑上即插即用（Windows / Mac / Linux 均支持）。
对话记录存在哪里？
存在 U 盘的 data/memory/ 目录。拔盘携带，下次插入继续使用。
首次启动很慢？
首次启动会自动安装 npm 依赖，需要 10-30 秒，后续启动秒开。
如何更换 AI 模型？
打开配置中心 http://127.0.0.1:18788/，重新选择模型和 API Key 即可。或直接双击 Config.html。
Mac 提示"无法打开，因为无法验证开发者"怎么办？
右键点击 Mac-Start.command，选择"打开"，在弹窗中再次点击"打开"即可。此操作只需一次。
本地模型需要什么硬件配置？
llama.cpp（便携版内置，仅 Windows）需 8GB+ 内存；LM Studio / Ollama 各平台通用，7B 模型建议 8GB 内存；vLLM 需要独立显卡（NVIDIA GPU 8GB+ 显存）。
如何完全卸载？
便携版直接删除整个文件夹即可。
如何升级版本？
Windows 双击 upgrade.bat；Mac/Linux 终端运行 cd app/core && npm install openclaw@latest --registry=https://registry.npmmirror.com。升级不影响 data/ 目录。
如何备份配置？
通过菜单 [6] 备份。配置保存在 data/.openclaw/openclaw.json，直接复制此文件即可备份。

配置中心功能

启动后浏览器自动打开 http://127.0.0.1:18788/，所有配置和管理操作都在这里完成。

步骤一：选择模型平台

  • 27 个平台供选择：国产 13 个 + 国际 8 个 + 聚合 3 个 + 自定义中转 + 本地
  • 点击卡片展开，选具体模型 + 填 API Key
  • 自定义中转：Base URL + 模型名 + Key 一步到位
  • 本地模型（LM Studio / Ollama）：自动检测端口和模型列表

步骤二：启动 + 命令面板

打开聊天界面

跳转到 OpenClaw Gateway（如有渠道配置会先保存）

更新

检查 GitHub Releases，新版自动下载并备份回滚

诊断 / 引导

提示用户在终端运行 openclaw doctor / onboard

重启 Gateway

无需关闭终端，一键重启使配置生效

渠道配置（12 个平台）

启动页底部展开，填凭证后点测试。打开聊天时自动保存到配置：

  • Bot Token 类：Telegram、Discord、Slack、QQ Bot、飞书、企业微信、LINE、MS Teams
  • 扫码类：微信（Web 扫码登录）
  • 命令行类：WhatsApp、Signal（提示运行 openclaw channels login）
  • JSON 凭证：Google Chat（Service Account）

配置管理

  • 导出配置：下载 openclaw-config.json
  • 导入配置：上传 JSON 恢复，自动 reload
  • 查看 JSON：弹窗显示当前完整配置
  • 重新配置：恢复最小默认配置（保留 sessions/memories）
  • 查看日志：展开 Gateway 日志面板（最近 80 行）

顶部状态栏

  • 绿点 + Gateway 运行端口（18789）
  • "打开聊天" 快捷链接
  • 动态版本号（从 PORTABLE_VERSION 读取）

后台机制

  • 心跳检测：每 5 秒 ping /api/heartbeat，连续 3 次失败显示全屏断连提示
  • Gateway 检测：每 15 秒扫描 18789-18799 端口
  • 更新流程：完整备份 → 下载 → 解压 → 覆盖 → 失败自动回滚
